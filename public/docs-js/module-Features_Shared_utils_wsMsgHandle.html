Features/Shared/utils/wsMsgHandle

Manejador de comunicaciones WebSocket para la interacción con el hardware. Procesa opcodes para la sincronización de presets, carga de datos y streaming. Gestiona buffers internos para reensamblar mensajes fragmentados recibidos en chunks.
